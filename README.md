# 💪 My Library

A dark, no-nonsense gym companion built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**. Browse 12 lifts, add them to today's plan, and watch the week's work add up.

## 🛠️ Technologies Used

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- React Context API + localStorage
- FitLog API (https://api.abcz.workers.dev/api/fitlog)
- Vercel deployment

## ✨ Key Features

1. **Workout Library** — Responsive grid of 12 workouts with live search-ready cards
2. **Today's Plan & Saved Tabs** — Live navbar badge counters, 5-lift cap, localStorage persistence
3. **Detail Pages** — Full specs, instructions, Add-to-plan / Save with toast feedback
4. **Live Metrics** — Exercises, minutes, calories calculated in real-time
5. **Sort & Filter** — Sort by duration, calories, or rating (high → low)
