# 💪 My Library

A dark, no-nonsense gym companion built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**. Browse twelve lifts, add them to today's plan, lock in your workout, and watch the week's work add up.

---

## 🛠️ Technologies Used

- **Next.js 15** (App Router) + **TypeScript**
- **Tailwind CSS v4** — utility-first styling
- **React Context API** — global state management
- **localStorage** — plan/saved persistence
- **Google Fonts** — Oswald (display) + Inter (body)
- **Vercel** — deployment

---

## ✨ Key Features

1. **Workout Library** — responsive grid of 12 workouts fetched from FitLog API
2. **Today's Plan & Saved Tabs** — live navbar badges, 5-lift cap, localStorage persistence
3. **Detail Pages** — full specs, step-by-step instructions, Add/Save with toast feedback
4. **Live Metrics** — exercises, minutes, and calories update instantly as you plan
5. **Sort & Search Ready** — sort by duration, calories, or rating with dropdown
